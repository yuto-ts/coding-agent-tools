`$ARGUMENTS` で指摘された表現を、ai-writing-check の NG ルールとして登録する。
引数が無ければ、直前の会話でユーザーが指摘した表現を対象にする。

## 手順

1. **ルールファイルの実体を特定する。**
   `readlink -f ~/.claude/hooks/ai-writing-check/rules.jsonl` を実行する。
   シンボリックリンクならリンク先(リポジトリ側)を編集する。

2. **重複を確認する。** 同じ表現・同じ意図のルールが既にないか `grep` で調べる。
   既存ルールで拾えるなら、パターンの拡張(選択肢の追加)にとどめる。

3. **正規表現を作る。** 誤検出を減らすため、語単体ではなく助詞・活用形まで
   含めて絞る(例: 「効く」なら `(が|に)効(く|きます)`)。行単位で照合される
   Python 正規表現であることに注意する。

4. **グッドパターンを必ず付ける。** 禁止だけでは不自然な回避文になりがちなので、
   `good` にはどう書き直すかの指針(可能なら具体例)を書く。ユーザーの補足が
   あればそれを反映する。

5. **JSONL を 1 行追記する。** 形式:
   `{"id": "<一意なid>", "pattern": "<正規表現>", "good": "<書き直しの指針>"}`

6. **検証する。** NG 表現を含むテスト文と、誤検出されそうな正常文を一時ファイル
   (`.md`)に書き、`python3 ~/.claude/hooks/ai-writing-check/check.py <file>` で
   NG 文だけが検出されることを確認する。テスト後に一時ファイルは消す。

7. **報告する。** 登録したルール(id・パターン・グッドパターン)と検証結果を
   1〜3 文で報告する。リポジトリ管理下なら commit するかをユーザーに確認する。
