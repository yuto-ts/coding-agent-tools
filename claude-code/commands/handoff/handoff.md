これまでのこのセッションの内容を、**別の Claude セッション(Claude アプリ / claude.ai / 別の Claude Code セッション)に貼り付けるだけで続きを依頼できる、自己完結したプロンプト**にまとめてください。

貼り付け先のセッションはこの会話を一切知らない前提で書くこと。以下を守ってください:

1. **自己完結**: 「さっきの」「前述の」など、この会話を前提とした表現を使わない。必要な背景はすべてプロンプト内に書く。
2. **含める内容**:
   - 目的・ゴール(何をしようとしているか)
   - これまでに分かったこと・決定事項(理由も簡潔に)
   - 現在の状態(何が完了していて、何が未完か)
   - 関係するファイルパス・URL・コマンドなどの具体情報(相手のセッションからアクセスできない場合はその内容を貼り込む)
   - 次にやってほしいこと(具体的な依頼として書く)
3. **含めないもの**: 試行錯誤の過程、失敗した打ち手の詳細(結論に影響する場合のみ「〜は試したがダメだった」と一行で)、この会話でしか意味を持たない省略語。
4. **出力形式**: プロンプト全体を 1 つの ```text コードブロックに入れて出力する(コピーしやすくするため)。コードブロックの外には補足を書かない。長さは内容に応じて調整し、不要に長くしない。
5. 貼り付け先が Claude Code でない可能性がある場合、ローカルファイルへのアクセスを前提とせず、必要なコード片や設定はプロンプト内に含める。
