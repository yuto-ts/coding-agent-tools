## 文字サイズ

**3段階だけを使う。** 段階が増えると視線の優先順位が壊れ、どこから読めばよいか分からなくなる。

| 段階 | 用途 | 目安(1280×720px の場合) |
|---|---|---|
| 見出し | スライドタイトル、強調する数値 | 36px ≒ 27pt |
| 本文 | 箇条書きの主文、メッセージ帯、図中ラベル | 24px ≒ 18pt |
| 補足 | 箇条書きの補足説明、図キャプション、引用、ページ番号 | 16px ≒ 12pt |

投影を前提とすると本文は 18〜24pt が下限とされる。24px(18pt)はその下限にあたるので、これ以上小さくするなら内容を削る。

情報密度を上げたいときにサイズを下げるのは最後の手段で、先に試すべきは**「主文(本文サイズ)+ 補足説明(補足サイズ)」の2段構成**にすること。視線の入口を主文に限定したまま、情報量だけを増やせる。

```html
<li>市販品の多くが袋・パウチ入り
  <span class="note">輸送時の保護と省資源の観点から、容器は薄く柔らかい方向へ</span></li>
```

強調は**太字とアクセント色だけ**で行う。サイズ変更・下線・斜体を強調に使わない。段階が増えるのと同じ問題が起きる。

## 配色

**白背景 + 3色**に収める。蛍光色と「赤+緑」の組み合わせは避ける(色覚特性による見分けにくさ、および投影時の彩度飽和のため)。

| 役割 | 例 | 使いどころ |
|---|---|---|
| ベース | 濃紺 `#1a2e4a` | 本文の文字、タイトル帯 |
| サブ | 淡い青 `#dce6f1` | メッセージ帯、表ヘッダ、補助的な囲み |
| アクセント | 橙 `#d95f02` | 強調。**1ページに1〜2箇所まで** |

アクセントを使いすぎると強調が強調でなくなる。「このページで一番言いたい数値」だけに使う。

背景に写真を敷かない。本文が読めなくなる。

## レイアウトと余白

- **1280×720px(16:9)固定。** `@page { size: 1280px 720px; margin: 0 }` で 1 section = 1 ページに対応させる
- **四辺に 48px 程度の安全マージン。** プロジェクタは端が切れることがあり、後方の席からは下端が見えないことがある
- **視線は上→下、左→右。** 「原因→結果」「従来→提案」「Before→After」は必ずこの向きに並べる。逆向きに置くと理解が一段遅れる
- **要素の左端・上端を揃える。** 揃っていないだけで雑に見える
- ページ番号は全ページに入れる。質疑で「12ページの図について」と指定してもらうため

## 引用の置き方

**背景・課題・関連研究には引用を付ける。** ここに引用がないと、主張が自分の思い込みなのか先行研究に基づくのか区別できない。

- 位置は**右下隅**、補足サイズ。本文の読みを邪魔しない
- 本文中では `[1]` のように番号だけを置く
- **番号はスライドの登場順**に振り直す。出典論文の参考文献番号をそのまま使うと、聞き手には順序が飛んで見える
- 完全な書誌情報は補足スライドに一覧として置く

書誌情報は必ず出典から転記する。出典PDFに参考文献ページが含まれていないことがあるので、その場合は検索して確認する。うろ覚えで書かない。

## 図解の使い分け

**対比・分類・割合は、箇条書きではなく図にする。** 箇条書きは「並列」しか表現できないが、研究の説明では要素どうしの関係のほうが重要なことが多い。

| 内容の型 | 図解 | テンプレートのクラス |
|---|---|---|
| 二者の対立・トレードオフ | 左右対比(中央に ⇔) | `.dilemma` |
| 従来 → 提案の転換 | 左右対比(中央に ▶) | `.row` + `.box.gray` / `.box.accent` |
| 2軸での位置づけ | 2×2 マトリクス(自分のセルを強調) | `.matrix` |
| 処理の流れ | 横フロー | `.flow` |
| 数値の比較 | 横棒グラフ | `.chart` |
| Before/After | 左右に画像 + 数値 | `.cmp` |

2×2 マトリクスは関連研究の位置づけに特に効く。空白セルが「未開拓領域」として一目で分かり、そこに自分の研究を置ける。

図は**1ページ1点**を基本にする(実験の写真列など、性質が同じものは複数可)。図が2点以上あるページでは、それぞれが何を言っているのかを説明する時間が足りなくなる。

## 情報量の設計

**1スライド1メッセージ。** 見出しをそのページの主張そのものにすると自然に守れる。「実験結果」ではなく「全対象で成功率90%以上」と書く。

盛りすぎもシンプルすぎも失敗する。

- **盛りすぎ**: 話さない情報が載っている。聞き手はそれを読もうとして話を聞かなくなる
- **シンプルすぎ**: 図だけ出して口頭で補う形。聞き手は後で内容を思い出せず、質疑で誤解が生まれる

削った詳細は**補足スライド**に置き、質疑で出たら見せる。式の導出、パラメータ表、失敗例、参考文献一覧などが典型。補足があると本編を思い切って削れる。

充填率(本文領域に対する内容の高さの割合)は **70〜95%** を目安にする。`scripts/check_layout.py` が測ってくれる。
