# 日本語スライドの文体

## 体言止めを使う

スライド上の文は**名詞で終える**。「〜します」「〜である」といった述語で終えない。

| 避ける | 使う |
|---|---|
| 変形量を66%削減しました | 変形量の約66%削減 |
| モデル化が困難です | 物理モデル化が困難 |
| 4種すべての注ぎに成功した | 4種すべての注ぎに成功 |
| この手法を提案します | 保持可能な最小把持力への追従 |

理由は2つある。**目が滑らない**こと(述語まで読まないと意味が確定しない文は、投影されたスライドでは読み切れない)と、**話すときに述語を自分で補える**こと(スライドを読み上げる棒読みになりにくい)。

見出しも本文も体言止めで統一する。ただし見出しは主張そのものにする。「実験結果」ではなく「全対象で成功率90%以上」。

**メッセージ帯だけは例外を許す。** 「〜を可能に」「〜が前提条件」のように、体言止めのまま主張を言い切る形にできればそれが最良だが、無理に名詞化して不自然になるくらいなら自然な言い回しを優先する。

### 体言止めにしにくいときの言い換え

- 「〜できる」→「〜が可能」「〜に対応」
- 「〜が必要だ」→「〜が必須」「〜の必要性」
- 「〜を防ぐ」→「〜の防止」「〜の抑制」
- 「〜に成功した」→「〜に成功」(サ変名詞はそのまま止められる)
- 「〜という設計方針を取った」→「〜という設計方針」

## 括弧と記号

- 全角括弧 `()` ではなく**半角括弧 `()`** を使う。全角括弧は前後に余分な空白ができて間延びする
- 読点は `、` 句点は原則使わない(体言止めなので文末に句点が来ない)。補足サイズの説明文で2文以上書くときだけ `。` を使う
- 数値と単位の間は半角スペース(`80 mN`、`158 mm`)。パーセントは詰める(`90%`)
- 範囲は `〜`(全角波ダッシュ)。`20〜80 mN`
- 意図的な字間には全角スペース `　` を使う。`単腕　158 mm` のように、対になる語と数値を離すときに効く

## フォント

```css
font-family: "Helvetica Neue", Helvetica, "Hiragino Sans",
             "Hiragino Kaku Gothic ProN", "Yu Gothic", sans-serif;
```

英数字を先に書くことで、ラテン文字は Helvetica、日本語はヒラギノにフォールバックする。日本語フォントを先に書くと英数字までヒラギノになり、数字が野暮ったくなる。

**Google Slides に持ち込む場合はヒラギノが存在しない。** `export_pptx.py` は `Noto Sans JP` を指定している。字幅が違うため折り返し位置がずれるので、変換後に見直す。

## 用語

- 初出の専門用語は補足サイズで一言だけ言い換えを添える。口頭でも補うが、スライドにないと後で思い出せない
- 英略語(DMP、PID、ROS など)はそのまま使ってよいが、初出時に何の略かを原稿(`script.md`)に書いておく
- 「本研究」「提案手法」は使ってよい。「我々は」「私は」は不要
